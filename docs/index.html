⚙️ Core Shield Engine
INIT IframeShield.init(options) Initialize the shield and start pre-emptive DOM interception
▼
Parameters
Parameter Type Required Description
options.action string Optional (default: 'sandbox') Mitigation action: 'sandbox' | 'remove' | 'blank'.
options.sandboxUntrusted boolean Optional (default: true) Automatically sandboxes third-party frames not in the trusted whitelist.
options.blockTrackingPixels boolean Optional (default: true) Neutralizes hidden 1x1 or 0x0 surveillance tracking frames.
options.trustedDomains string[] Optional Array of custom domain strings to always permit (e.g. ['partner.com']).

RESPONSE CODE: 200 OK 3ms
