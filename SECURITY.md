| Version | Supported          |

## Reporting a Vulnerability

Security is paramount to **iframe-shield**. If you discover a bypass, sandbox escape, or security vulnerability:

1. **Do not** disclose the issue publicly in GitHub Issues or Discussions.
2. Please report findings directly by creating a private GitHub Security Advisory or contacting the maintainer (**JOJIN JOHN**).
3. Provide detailed steps to reproduce the issue (including sample HTML, iframe payload, and browser version).

We commit to acknowledging your report within 48 hours and issuing a patch release promptly.

Thank you for helping keep the web and its users secure!
